# 访客检测预算设计复核（2026-10-17）

本次是既有访客检测表单与后台配置的普通功能扩展，采用 Operate 模式，帮助访客按模型、思考强度和协议选择合理预算。独立复核结论为 **SHIP**，未发现阻断交付的界面问题。

## 范围与现有视觉依据

沿用观察站与后台的浅绿背景、白色面板、深绿正文与操作色，中文系统字体 `'PingFang SC','Microsoft YaHei',sans-serif`，以及原生输入框、下拉框、既有焦点样式和响应式布局。视觉依据来自现有 `app/web/observatory.css`、`app/web/style.css`、页面组件及本次截图；代码差异没有 CSS 或全局 token 变更。

项目缺少 `PRODUCT.md`、`DESIGN.md`，但现有实现已形成一致体系。本次保留该体系，不补建全局设计文件、不引入新的视觉方向。新增控件在原有表单层级内扩展。

## 功能与交互

- 访客自动预算以 1200 秒／32768 token 为基础；high 放大 1.5 倍，xhigh 放大 2 倍，分别限制在 3600 秒／128000 token 内。时间和输出上限均可独立手动选择，显式选择优先于自动计算。
- 思考强度补充“不发送（接口默认）”、none、minimal。协议说明位于相关控件旁；仅选择 Chat Completions 时显示输出长度参数，可选 `max_completion_tokens` 或 `max_tokens`。
- 预算摘要随思考强度、时间、输出上限及协议变化更新，使用 `role="status"` 与 polite live region；提交成功后显示实际执行时间预算。说明明确两项检测并行、重试共享时间预算、上游可能计入推理 token。
- 后台在“开放访客独立测试”之后增加两项基础预算字段，提供显式标签、数值范围与倍率说明。保存后回填配置，返回访客页可看到新基础预算；访客基础配置与后台定时请求配置独立。

## 限制与非阻断建议

- 390px 下并排原生下拉框的长选中文案存在轻微裁切，主要涉及协议和“不发送”说明。标签、展开选项和邻近帮助文字仍保留含义；后续可在最窄断点将这组控件纵向排列。
- 新选项使表单更长，Chat 配置展开后需要继续滚动；当前纵向层级与主操作仍清晰。共享样式中已有小字号、对比度、阴影／光晕等检测提示，部分涉及被后续规则覆盖的声明，本次不将其认定为新增回归，也未扩大为整站样式修复。
- 截图未独立展示全部加载、错误和键盘焦点状态；这些路径依据既有标记、处理函数和相关测试复核，未进行独立屏幕阅读器验收。
- 本地通过不代表所有上游模型均兼容。复核交接时，真实 API 的 medium 糖果题已通过，xhigh 仍在执行；外部结果须单独确认，不能据此宣称全部真实检测成功。
