# 访客检测记录设计复核（2026-10-17）

本次为现有后台的普通功能扩展，采用 Operate 模式：帮助管理员筛查检测失败、比较分项耗时并查看诊断。新增“访客检测记录”位于模型节点之后，提供状态／项目筛选、刷新、分页及原生折叠详情；公开页仅补充记录保留说明。既有导航、配置表单、节点管理和公开观察站的视觉结构保持原样。

设计依据为仓库基线中的 `app/web/style.css`、后台组件和当前截图。项目没有 `PRODUCT.md`、`DESIGN.md`；这次不创建、补写或修复全局设计文件，也不建立新的视觉方向。

## 响应式与交互检查

- 桌面采用五列表格：任务、模型／接口、结果、耗时、诊断。800px 以下转为每条记录两列，字段名称就地显示，诊断横跨整行；520px 以下标题与刷新操作换行，分页按钮至少 44px 高。
- 已查看 1440px 桌面和 390px 手机整页截图，以及各自记录区截图。长 ID 可换行，展开诊断可读，现有配置区布局保留，截图中未见横向溢出或裁切。
- 源码覆盖读取中、无记录、筛选无结果和请求失败提示；读取时禁用筛选与翻页，完成后恢复。切换筛选回到第一页，末页／首页按钮禁用。退出或鉴权失效会清空记录并使迟到响应失效。
- 标题与区域、筛选与标签显式关联；桌面表格保留 caption 和列头；结果同时提供文字和颜色；数量摘要使用 polite live region，错误使用 alert，读取状态标记 `aria-busy`。原生控件和详情保留键盘交互及既有焦点样式。未进行独立屏幕阅读器或完整 WCAG 验收。
