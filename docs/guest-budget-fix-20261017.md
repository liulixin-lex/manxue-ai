# 访客检测预算与兼容性修复（2026-10-17）

项目为 156.238.224.151 上的 test.gguuai.com / manxue-ai。修复基线为 a53bc6a，原运行镜像 manxue-ai:visitor-history-fbb8620。

## 行为

访客请求不再固定使用 DEFAULTS 中的后台 300 秒 / 16000 token。新增独立持久化设置 guest_timeout_seconds=1200 和 guest_max_output_tokens=32768，由管理员配置，自动模式按用户选择的 effort 放大。

| effort | 默认总时间预算 | 默认输出上限 |
| --- | ---: | ---: |
| 不发送、none、minimal、low、medium | 1200 秒（20 分钟） | 32768 token |
| high | 1800 秒（30 分钟） | 49152 token |
| xhigh | 2400 秒（40 分钟） | 65536 token |

自动模式不根据模型名称做不可靠的猜测。任意模型名称仍允许提交；模型是否支持选中的 effort、协议与 token 上限由其接口能力决定。不支持 reasoning 参数的接口可选“不发送”，需要显式 none/minimal 的模型也可以选择。

访客可覆盖单次 timeout_seconds（60–3600 秒）、max_output_tokens（1024–128000）；网页提供常用档位，API 校验整数边界、拒绝布尔值。自动放大后也不得超过 3600 秒 / 128000 token。输出上限含不含推理 token 取决于接口定义，页面显示提示。Chat 接口可显式选择 max_completion_tokens 或 max_tokens；不自动替换模型、协议或思考强度，以保留检测意义。

## 请求链路

- 访客 HTTPS 读取取消独立的 90 秒无数据限制，等待受当前请求剩余时间和父进程硬截止时间限制。适用于 Responses 流式响应和 Chat 非流式响应，长时间推理没有输出时不会仅因 90 秒静默被中断。
- 保留 TLS 证书验证、公网 IP 校验和连接固定 IP、禁止重定向、响应大小限制、请求子进程隔离与取消、4 个访客请求并发/每地址密钥组合 2 个并发。
- 两项检测并行，共用有界整轮截止时间；队列最多等待 10 分钟，执行预算从 worker 开始时计时。请求并发名额等待计入执行预算。
- 临时错误保留有限重试与退避；最小重试剩余预算为 min(120 秒, 整轮预算/4)，不足时明确记录 retry_skipped，避免临近超时再发可能计费的请求。一次慢生成可使用全部剩余预算，不为凑重试次数提前切断。
- 总预算、生成预算、排队、输出不完整、上游生成失败等使用稳定错误码映射固定提示，不再把预算耗尽泛化为连接异常。HTTP 400 提示检查模型/effort/输出参数；401/403/404 不盲目重试。
- 后台生成预算、判分标准和站点模型配置保持。新字段自动以默认值补入旧库，历史诊断记录保留新任务的实际预算和 token 参数。

## 验证

- 完整候选镜像回归 161 项全部通过，包括真实 Chromium。新增 11 项测试覆盖 7 种 effort × 2 种协议、管理员独立配置和重启保存、手动边界、双项执行得到大于旧 300 秒的预算、剩余预算不足不重试、早期临时故障可重试及 404 不重试、请求体 effort/token 参数、95 秒静默推理模拟、地址/TLS 防护保留、页面预算预览与后台保存。
- 真实接口测试使用原站点自有节点凭据，在隔离候选服务中通过访客 HTTP 提交，不复制或公开密钥。medium 糖果 22.949 秒通过；xhigh 鹈鹕 403.566 秒通过基础校验，证明生成跨越旧 300 秒仍可成功完成；xhigh 糖果独立复测 51.091 秒通过。
- 首次 xhigh 双项测试主动设置不重试，其中糖果在 23.855 秒收到上游生成失败，鹈鹕最终成功；后续糖果复测成功。这个失败保留在验证证据里，不能声称所有调用无故障。扩大本地预算无法修复接口服务商自身的 404、鉴权、额度或生成故障。
- 页面沿用原视觉系统；桌面和手机无页面横向溢出，独立复核结论 SHIP。少数原生下拉选项文字在窄屏闭合时裁切属于非阻断问题。

修复上线后，真实公网 Responses + xhigh 双项在 382.539 秒全部通过；Chat Completions + 不发送 effort + max_tokens 的糖果题也已通过。上线提交、备份和最终结果见 guest-budget-deployment-20261017.md。新增功能以真实返回内容判分，不通过修改答案标准或吞掉错误制造成功率。
