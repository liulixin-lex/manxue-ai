# 主体识别审核 v4：纠正卡通图误判

日期：2026-09-26。生成测试仍为 v3；视觉判定版本为 v4；renderer 为 v3。

## 实际问题

线上第 301–303 轮七项检查中六项为真，仅 loop 为假就整幅判为 invalid。抽查原始截图可清楚辨认鹈鹕、自行车及骑乘构图。采样窗口结束时，脚踏、云朵、风车可能不在共同周期边界；首末帧不同不能证明循环跳变。第 295 轮也是仅循环一项失败。此外，旧提示词对脚踏接触和橙色嘴的要求过细，不适合简化卡通的主体识别。

此外，原界面只要任一测试 invalid，就在鹈鹕图上显示“内容校验未通过”，包括独立的糖果题答错，提示对象错误。

## v4 判定契约

- 核心：可辨识的鹈鹕/有代表性长嘴的卡通水鸟、可辨识自行车、直观的鸟在车上骑乘构图。允许任意颜色、简化结构、遮挡、夸张比例和脚踏轻微错位，不要求逐帧工程接触。明显其他动物不应通过。
- 建议：动作、场景、校验码视觉清晰度、循环。保持原始布尔/未知观察和证据，但不否决主体。SVG 基础安全、动画声明和 nonce 源码校验仍然有效。
- 主体否定至少引用两张不同编号帧；只有两次请求对同一核心项均明确否定才标主体不符。第二次看相同截图，不提供第一次的判词。默认仍是同一模型的两次请求，不宣称不同模型的独立共识。
- 一次否定、两次分歧、未知或复核预算不足均为待复核，不能为了得到通过而无限重试。三项肯定才主体通过。仅建议项不足不发起第二次请求。
- 网络重试、格式修复和第二次观察共用审核总时间和请求次数上限。复核接口失败保留已有观察为待复核；初次审核不可用仍为执行异常。
- 所有已知动画必须无限重复，首末时间差为各自周期（含 CSS alternate）的整数倍，且没有延迟/未知/截断风险，才声称采样覆盖共同边界。否则 loop 为未知，同时保存裁判原始观察。
- 截图无变化仍可判断主体，动作标为未知，避免用动画采样问题否定正常静态构图。

## 历史数据与界面

启动时对具有完整旧观察的 v3 测试作版本化重新归类：旧规则已认可的三项主体可沿用；旧规则主体否定只能转待复核，不伪装成新模型通过；建议项不再否决。原审核完整保存在 previous_review，policy_reassessment 标明沿用旧观察、未重新请求模型，详情可展开查看。再次启动不重复迁移。

糖果题、SVG、截图、nonce、时间、请求用量、凭据均不修改；整体状态仍独立汇总糖果与鹈鹕结果。API/渲染异常记录不自动改为通过。真实重放报告单独保留，不回写历史 AI 结论。

图片仅在 v4 核心问题经两次确认时显示“AI 复核：主体不符”。糖果题错误、未知、旧版否定均不再给图片贴“不合格”角标。界面明确“主体通过”，不表示专业动画细节全部达标。

## 验证边界

回归包含建议项假/未知、不同周期、静态采样、缺少有效证据、确认一致/分歧/超时/次数限制、历史迁移幂等、原始输出与糖果判分保留、桌面/移动界面。真实截图重放用于检查已知案例，负例用于确认规则没有退化为全部放行。少量案例不构成总体准确率或误判率统计；仍需独立人工标注保留集。
