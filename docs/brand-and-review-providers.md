# GGUUAI 品牌、推广位与独立审核提供商

## 管理员操作

- 首页与后台左上角使用 GGUUAI 品牌，页面标题同步更新。
- 后台「首页推广位」填写标题、介绍（选填）、跳转链接及按钮文字，启用并保存后展示在首页顶部中间。未配置有效链接时不可启用；关闭后不占位。推广位只输出文字与安全的 HTTP/HTTPS 链接，不接受 HTML、脚本或外部嵌入内容。
- 后台「视觉审核」选择同模型自评，或新增审核提供商后选择外部模型审核。保存提供商不会自动切换审核方式；还需保存系统配置。
- 提供商可配置名称、API 地址、密钥、视觉模型 ID、Chat Completions / Responses 协议。仅支持这两类兼容接口，不把原生 Anthropic / Gemini 协议误当成兼容接口。
- 非推理视觉模型默认不发送思考参数；Chat 默认使用 max_tokens，可按提供商要求切换到 max_completion_tokens。Responses 使用 max_output_tokens。审核思考强度的显式系统覆盖仍然生效。
- 「验证读图」发送两张即时随机颜色顺序的 PNG，检验是否能读取真实图片。最多一次请求、60 秒；结果只说明图片通路可用，不代表所有复杂画面都能准确识别。编辑提供商配置会清除旧验证状态。
- 这些审核设置用于站点定时检测及管理员节点单次检测。访客自测继续使用访客自己的凭据并明确标记基础校验，不调用站点付费审核提供商。

## 审核契约与稳定性

- 自评与外部模型使用同一主体识别标准；不是更换提供商就改变评分尺度。核心仍为鹈鹕、自行车、直观骑乘关系，允许卡通简化。动作、背景和循环是独立建议项。
- 规则位于 Responses instructions / Chat system 消息；场景、校验码及带编号与时间戳的 12–16 张实际截图作为用户内容，不传入生成模型的自述或源代码当作视觉证据。
- 图片中的文字不构成指令。看不到图片或证据不足时必须给未知；核心否定至少两帧并进行第二次观察，分歧/预算不足保留待复核。复核用相同截图及采样边界信息，不把首轮结论传给模型诱导确认。
- 结构化 JSON 输出支持既有自动兼容回退、严格模式和提示词 JSON 模式；格式修复、临时请求重试和复核共用已有次数与时间预算。不会把无法解析或网络异常伪装成画面内容不符。
- 外部模型失败不切换到自评。记录所选提供商 ID、请求模型、返回模型、协议、思考设置、实际截图和审核回执；编辑配置不改变已经启动的请求快照。
- 读图验证与回归案例不能证明总体准确率；模型仍可能误判，应结合保留的帧证据检查有争议的结果。

## 数据与凭据

外部审核凭据保存在独立 review_providers 表，不混入生成节点或公开 state。后台列表仅返回脱敏地址和密钥；修改地址要求重新填写密钥。旧 judge_node_id 配置在启动时复制为独立提供商，保留原生成节点、历史记录与审核结果；迁移幂等。

推广配置属于公开内容，只有启用时才进入公开 API。未提供真实推广地址与外部模型凭据时不自动猜测或开启。
