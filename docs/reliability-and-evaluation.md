# 检测稳定性与视觉审核 v2

本次实现保持单实例 Python、SQLite 与 Playwright 部署。它修复执行和截图链路的可复现缺陷，增加审核证据与独立裁判配置；不声明自动判分已经达到人工水平。

## 执行和故障恢复

- Docker `init: true` 回收 Chromium 后代进程。
- 生成和审核分别使用有截止时间的有限重试；支持临时 408/429/5xx、退避抖动和 Retry-After。鉴权及明确配置错误不盲目重试。
- 每次真实 API 请求使用短生命周期进程。父进程截止时间覆盖 DNS、TLS、响应头和响应体；取消会终止进程组。请求凭据只经 stdin 传递。
- 后台最多同时两个 API 请求、访客最多四个，每个地址与凭据组合最多两个。访客排队超过十分钟则结束，不发出已过期请求。
- SSE 增量解析并限制单事件/整体大小，收到完整终结事件后结束读取；仅 `[DONE]` 不算成功。响应体连续无数据最多等待 90 秒，总请求预算仍为硬上限。
- 后台生成预算为 `timeout_seconds`，截图含排队最多 45 秒，审核为 `review_timeout_seconds`（默认 120 秒）。整轮预算为三者之和，所有子阶段受剩余时间约束。
- runs 增加 `lease_until`。单实例调度器扫描超期和已退出的 worker，保留已有成果并释放任务阻塞。数据库暂时不可写时保留恢复意图，恢复可写后重试收尾。
- 已结束任务拒绝迟到写回。重启不会自动重发可能已计费的生成请求。
- SVG 校验通过后立即保存，截图保存后再次更新阶段；审核 API 失败不再丢失已有动画和截图。
- SQLite 使用 WAL；连接明确关闭。使用 SQLite backup API 做一致性备份，不能只复制运行中的主数据库文件。

## 渲染与审核契约

生成测试定义版本为 3，视觉 rubric 与 renderer 版本为 2。

- 完整 XML 根节点提取支持嵌套 SVG，限制 2 MB 输入、20,000 节点、128 层深度。保留禁止脚本、外部图片/字体/链接与危险动画属性的检查。
- 不再覆盖 SVG 背景、viewBox、根元素宽高或 overflow。围绕其实际尺寸建立 viewport，最大单边 4096；截图等比缩小到 960×640 以内。
- 默认取 12 帧；存在较短周期时额外采样一个短窗口，最多 16 帧。覆盖声明的动画延迟、长周期及 CSS alternate，观察窗口最多 12 秒。
- SMIL 与 CSS 分别显式暂停、定位，再等待浏览器绘制；记录浏览器版本、视口、时间轴、每帧时间与哈希。
- 无法解析或超预算的时间轴标记 `sampling_limited`；不能将未采到的动作直接当作不存在。所有采样帧相同时返回“证据不足”，不调用视觉 API 凭空判断动作。
- 新裁判 schema 包含 `checks` 与 `evidence`，检查鹈鹕、自行车、骑乘、动作、场景、可见 nonce 和循环，明确结论必须引用有效帧编号。
- 内容不合格为 `invalid`；证据不足为 `uncertain`；渲染/API/保存故障为 `error`，并附阶段和固定错误码。未知异常不直接公开其原始文本。
- 后台可选另一个已配置节点作为独立裁判；默认同模型自评并明确标识。独立节点应实际支持图片输入，系统不会默默替换成其他模型。
- 访客仍只做基础校验，明确显示“基础校验通过 · 未视觉审核”，不会借用后台裁判凭据。

## 截图证据与公开范围

截图及 manifest 存在 `/data/artifacts/<run_id>/`，图片 API 为 `/api/runs/<run_id>/frames/<index>`。与原项目的公开画廊一致，这些截图也是公开证据，不应输入机密内容。

文件用临时文件、fsync、原子重命名保存，已有 run 证据不覆盖；manifest 包含 SVG 哈希、PNG 哈希、时间戳、renderer 版本和浏览器版本。审核记录保存裁判模式、请求/返回模型、尝试次数、用量和证据编号。

PNG 默认保留最多七天，总容量约 1 GiB。清理保留正在执行任务的证据；数据库中的结果与哈希保留，过期 PNG 返回 404，页面显示证据不可用。保存前检查容量和磁盘余量；缺少存储预算时明确结束审核，不删除数据库记录伪造正常状态。完整永久归档可从数据卷进行一致性备份。

## 版本化统计

最近 24 小时统计按当前节点筛选。新版聚合只统计测试定义 v3，避免把更宽松的旧规则直接混入。旧记录和原判分继续保留并可查看，不做静默重评分。

糖果题要求最后一行输出 `最终答案：21`（或仅返回 `21`）；推理中的 21、否定答案、多个候选和小数不算通过。旧版详情继续展示旧判分说明。

画廊增加独立鹈鹕统计、证据不足筛选及截图证据。去掉没有相应行为的“降智 · 自动删除”标签。

## 健康与上线

`/api/health` 检查数据库读取、调度心跳、最近本地截图自检及是否有未完成的故障恢复。启动和空闲期间约每五分钟运行一次本地截图自检，不请求付费模型。上游失败不会被当作渲染器故障或引发自动容器重启。

部署前停止接收新检测，等待当前请求结束，用 SQLite backup API 备份数据库及需要保留的证据。重建容器应用新的镜像和 healthcheck。迁移只增加字段，旧记录保留；旧服务若回滚不能识别新版状态/证据，应一起回滚界面或保留数据后恢复先前备份。

本分支只实现并测试代码，不会自动推送 GitHub 或替换现有生产容器。

## 自动化验证

```sh
python -m unittest discover -s tests -v
docker build -t manxue-ai:test app
docker run --rm --init --network none --pids-limit 256 --memory 1g --cpus 1 \
  --tmpfs /data --mount type=bind,src="$PWD/tests",dst=/tests,readonly -w / \
  -e PYTHONDONTWRITEBYTECODE=1 -e RENDER_TESTS=1 \
  manxue-ai:test python -m unittest discover -s /tests -v
docker run --rm --init --network none --pids-limit 256 --memory 1g --cpus 1 \
  --tmpfs /data --mount type=bind,src="$PWD/tests",dst=/tests,readonly -w / \
  -e PYTHONDONTWRITEBYTECODE=1 manxue-ai:test python /tests/soak.py --iterations 500
```

单元测试不需要 Playwright；浏览器与端到端测试由 `RENDER_TESTS=1` 启用。CI 只挂载测试文件，直接验证镜像内的应用代码，运行浏览器测试和 20 次带强制超时的生命周期回归。soak 可自行增加次数，不调用上游模型。

以上测试使用临时目录，不启动 `/data` 内的正式服务。若用 tmpfs 验证正常启动，需提供 `--tmpfs /data:uid=10001,gid=10001,mode=0700`，使数据目录对镜像的非 root 用户可写；默认生产 Compose 使用命名数据卷。
